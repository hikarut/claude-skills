# ポンチ絵作成（16:9画像）

HTML（1280×720）でスライドを組み、`scripts/render.py` で PNG（2560×1440）に書き出す。
目指すのは、**文字を読まなくても、絵と配置で言いたいことが伝わる**スライド。1つの主張を、1つの図とイラスト・アイコンで見せ、文字はそれを補う。

## 構成
1. **スライドタイトル**：テーマを名詞句で（40px・極太）。
2. **キーメッセージ**：結論を1文で（22px・標準の太さ・1〜2行）。結論の語句1〜2か所だけ `.em` で強調する。`<br>` は入れない。
3. **コンテンツ**：主役の図を1つ。
4. **フッター**：右下にコピーライト、数値や記事を使ったら左下に出所。

タイトル・キーメッセージ・コンテンツの間の余白とフッターの位置は `templates/base.html` で決まっているので変えない。

## 手順
1. **伝えることを決める。** 一番言いたいこと（so what）を1つに絞り、キーメッセージにする（「〇〇の動向」ではなく「だから何か」）。キーメッセージが決まらなければユーザーに確認する。
2. **図の形を決める。** 要素どうしの関係（原因→結果、課題→打ち手、比較、流れ、構造）を決め、それが見える形を選ぶ。近いお手本（`examples/*.png`）を Read ツールで開いてトーンをつかむ。数字の比較・推移・構成比などは `references/charts.md` のグラフ・図解から選ぶ。
3. **絵を選ぶ。** 下の「絵（アイコンとイラスト）」に沿って、主な要素ごとにアイコンの絵を決める。イラストは、場面や人を見せると伝わりやすくなる場所があるときだけ選ぶ。
4. **組む。** `templates/base.html` と `theme.css` を出力先にコピーし、`.content` の中に図を組む。メインカラーの指定があれば、コピーした `theme.css` の `--main` を書き換える。
5. **書き出して確かめる。**
   ```bash
   python3 ~/.claude/skills/ponchi-e/scripts/render.py slide.html slide.png
   ```
   `WARN:` が出たら直して書き出し直す（文字の小ささ、絵がない、間延びしたカード、詰まりすぎ、空きの固まり、はみ出し、文字数の多さ、大きすぎる数字を警告する）。Playwright のブラウザが別の場所にある環境では `CHROMIUM_PATH=<chrome のパス>` を付ける。最後に PNG を Read ツールで開き、下の「仕上がりの確認」を見る。
6. HTML・PNG・`theme.css`・（使った場合は）イラストの SVG を同じフォルダに保存する（指定がなければカレントディレクトリ）。

## 絵（アイコンとイラスト）
文字とカードだけのスライドは分かりにくい。主な要素には絵を添えて、文字を読まなくても何の話かわかるようにする。**基本はアイコンの絵で、シンプルにする。**
- **アイコンの絵（基本）**：図の主な要素（入力・仕組み・出力、工程、比較する案など）には、Lucide のアイコンを淡色の円に入れた `.badge` を添える。大きさは要素の重みに合わせて 56〜96px。主役の要素だけ `.badge.main`（メインカラーの円に白いアイコン）にする。グレーの面の上では `.badge.white` にして、円が背景に埋もれないようにする。名前は https://lucide.dev/icons で、具体的なものを表す名前を探す（例：データ基盤 `database`、ストリーム `activity`、知識 `book-open`、判断 `scale`、AI `bot`、人 `users`、店舗 `store`）。
  ```html
  <span class="badge" style="--s:72px"><i class="icon" style="--i:url(https://unpkg.com/lucide-static@0.460.0/icons/database.svg)"></i></span>
  ```
  カードやパネルの見出しの横には、小さなアイコン（`.icon`、24〜30px、グレーの線）を付けてよい。1つの要素に、大きな絵と小さなアイコンを重ねて付けない。
- **イラスト（必要なときだけ）**：人の行動や利用の場面を見せると伝わりやすい場所（インプットとアウトプットの円、事例カードなど）にだけ、1枚に0〜2点まで使う（事例カードのように同じ重みの項目に添える場合は項目の数まで）。内容に合うものがなければ使わず、アイコンの絵にする。unDraw から英語キーワードで探し、メインカラーに色を合わせて保存する。
  ```bash
  python3 ~/.claude/skills/ponchi-e/scripts/undraw.py search "data server"
  python3 ~/.claude/skills/ponchi-e/scripts/undraw.py get <URL> <出力先>/il_data.svg
  ```
  同梱のイラスト（`examples/il_*.svg`：`il_collect` データ・サーバー、`il_act` 人と画面、`il_finance` ビジネスパーソンとグラフ、`il_retail` 買い物、`il_telecom` スマートフォン）は、内容に合うときだけ `recolor` で色を合わせて使う。HTML では `<img class="illust" src="il_data.svg" style="height:160px">` のように読み込む。
  ```bash
  python3 ~/.claude/skills/ponchi-e/scripts/undraw.py recolor ~/.claude/skills/ponchi-e/examples/il_collect.svg <出力先>/il_collect.svg
  ```

## 文字の強弱
文字は3段階以上に分け、ひと目で「見出し → 中身 → 補足」の順に読めるようにする。最小は16px（出所・コピーライトのみ13px）。

| 役割 | 大きさ | 太さ |
|---|---|---|
| 主役の数字（`.num`） | 48〜64px（単位は半分の大きさ） | 極太 |
| 比較の数字 | 32〜40px | 太字 |
| パネル・カードの見出し、図のラベル | 22〜26px | 太字 |
| 本文・説明 | 18〜20px | 標準 |
| 補足・注記・チップ | 16〜17px | 標準（注記はグレー `var(--sub)`） |

- 各カードは「太い見出し（一言の結論）＋短い説明（1〜2行）」にする。見出しと説明が同じような大きさ・太さで並ばないようにする。
- 数字は文章に埋めず、`.num` で独立させて大きく置く。主役の数字1つだけをメインカラーにする。
- 入りきらないときは、文字を小さくせず、説明を短くするか情報を削る。コンテンツの文字数は 200〜250字が目安（300字まで）。
- 説明は意味の切れ目で `<br>` を入れて改行し、1〜2文字だけが次の行に送られないようにする。

## 余白
- 余白の値（パネルの内側 24px、カードの内側 上下18px・左右24px、カードどうし 14px など）は `base.html` の部品（`.panel`・`.card`）で決まっている。スライドごとに `padding` や `gap` を書き換えない。
- **無駄な空きを残さない。** カードの中で文字が小さく固まり、上下や右に大きな空きがあるのは間延び。カードを縦に引き伸ばして埋めず、イラストや数字を大きくする、説明を1行足す、カードを横に並べるなどして、中身でカードを満たす。
- **詰め込まない。** カードの内側の余白は削らない。1パネルのカードは3〜4つまで。
- 主役の図はコンテンツの領域いっぱいに置き、下や右に大きな空きを残さない。図の下に補足の帯や点線を足さない。

## 色と形
- メインカラー（`var(--main)`）は結論にあたる1か所だけに使う：主役の要素、結論につながる矢印、主役の数字、`.em`。それ以外はチャコール・グレー・淡色（`var(--tint)` など）。図の中で一番目立つ要素が、キーメッセージの結論と一致するようにする。
- 本題の範囲は淡色の面（`.soft`）、補助はグレーの面（`.soft-gray`）。ラベルは濃いグレーのピル（`.pill`）、主役だけ `.pill.main`。
- 要素の関係は配置と矢印で見せる（左から右、上から下）。矢印は線＋三角で、結論につながるものだけメインカラー。
- 角丸は2種類：面・パネル・カードは `var(--r)`（16px）、小さな箱・ラベル・画像の枠は `var(--r-sm)`（8px）。
- 色コードを直接書かない。メインカラー以外の色相、グラデーション、影、絵文字、区切りの罫線や点線は使わない。

## 仕上がりの確認
- 文字を読まなくても、絵（アイコン・イラスト）と配置で何の話かわかるか。絵が多すぎてうるさくないか
- 一番目立つところが、キーメッセージの結論と一致しているか
- 見出し・本文・補足・数字に、はっきりした強弱があるか
- 間延びしたカードや空きの固まりがなく、逆に窮屈でもないか
- はみ出し、文字の切れ、重なり、不自然な改行がないか
