## 発信の方針（けんすう理論）
スプレッドシートの「けんすう理論」のシートにまとめている方針（ハイパー企業ラジオでのけんすうさんの話）。投稿文を作るときの前提にする。
- 発信は3つに分けられる：information（情報）、opinion（意見）、diary（日記）。
- **information だけを発信するのが良い。** 知らない人の意見や日記には興味を持たれない。フォロワー10万人を超えるまでは意見を投稿しない方が良い。opinion でバズらせようとすると過激な意見を言う羽目になる。
- information の優先順位：
  1. みんなが知りたくて、みんなが知らない情報（最優先）
  2. みんなが知りたい情報で、すでに知っている情報。興味がある情報なら何回流れてきても見るので、受けるネタは何回投稿しても良い（毎回違う人に届いている）
  3. みんなが知らないけど、興味がない情報。発信しがちだが刺さらない
- 投稿のポイント：
  - 時事性とタイミング
  - ツッコミの余白を作る
  - 言及したくなるようにする
  - 見た人が主役になれるようにする

このため、投稿文は information を基本にする。opinion はユーザーに頼まれたときだけ作り、その場合も記事などの情報を起点にする。

## 言い回し
- **常体（だ・である調）で書く。** 「です・ます」はほぼ使わない（直近684件中4件）。新年の挨拶などの日記だけ「〜と思います！」になる。
- **絵文字とハッシュタグは使わない**（絵文字0件、ハッシュタグ3件）。「！」もほぼ使わない。
- 冒頭は、記事が何かを1文で言い切る体言止めが多い。
  - 「〇〇を整理した記事。」「〇〇による〇〇の解説。」「〇〇が〇〇を発表。」「〇〇の比較用資料。」
- 次に、記事の中で**一番効いている指摘を「」で引用**し、それへの評価を書く（「」は直近684件中280件で使用）。
  - 「〜という指摘がとても重要。」「〜という整理が分かりやすい。」「〜という視点が参考になる。」
- 締めは、自分の評価や示唆を短く。よく使う文末：
  - 「〜が参考になる」（直近684件中123件。最も多い）、「〜がとても重要」、「〜が分かりやすい」、「〜になっている」
  - 意見は断定しすぎず、「〜と思う」「〜気がする」「個人的には〜と思っている」でやわらげる
- 「とても」をよく使う（「とても重要」「とても参考になる」）。「めちゃくちゃ」「マジで」などのくだけた強調は使わない。
- 要点を並べるときは「・」の箇条書きか、①②③を使う。
- URL は本文の後ろ（1〜2文の後）に置き、URL から始めない。

## 投稿の型
### information（記事の紹介）— 主力。2025年以降の投稿の約8割
1. 何の記事か（体言止め1文。発信元や対象を入れる）
2. 記事の要点（数字・対比・整理の枠組みなど、具体的な中身を1〜2文）
3. 評価・示唆（「〜という指摘が参考になる」「〜という整理が分かりやすい」）
4. URL（必要なら、その後に「・」の箇条書きで要点を2〜3点）

### opinion（自分の意見）
- 「よくある失敗パターンとして〜」「〜が見落とされがち」「〜は実は少ない」のように、通説とのズレや現場の実感から入り、理由と打ち手で締める。
- 経験（前職の組織立ち上げ、研修・コーチング、SQL の本）を根拠にすると、この人らしさが出る。

|---|---|
| 区分 | information はエンゲージメント率の中央値 3.9%、opinion は 1.7%。インプレッションの中央値も information（698）が opinion（570）より高い |
| 振り返りメモ | 「感想系投稿は伸びない」「投稿するならもっと尖っているとか共感できるとかの内容にしないとダメ」（2025年） |
| URL | URL ありはエンゲージメント率 3.9%、なしは 1.6%。ただし「URL付きが多すぎてスパムっぽくなってる？」という振り返りもある |
| 画像 | 画像ありはインプレッションの中央値 1,068、なしは 483 |
| 長さ | 短い投稿（80字未満）は伸びにくい。140字以上（ウェイトでおおむね 230〜280）がエンゲージメント率 3.4% で最もよい |
| 投稿時間 | 8時台が中心。振り返りメモでは「7時台は見ている人が少ない」「夜は反応が悪い」。8時台を勧める |
| 2026年のテーマ | インプレッションの中央値は、ナレッジグラフ 6,123、オントロジー 4,368、セマンティック 4,290、Palantir 3,986。2026年全体の中央値は 876。エージェント（1,004）や MCP（562）だけの話題は伸びにくい |
| 再投稿 | 「ニーズのある情報は何度流しても一定伸びる」（2025年）。過去に伸びた投稿の再投稿も選択肢になる |
| AI の出力 | 「Claudeに要約してもらった内容そのまま投稿 → URLが間違っている」（2025年）。URL は必ず実物を確認する |
