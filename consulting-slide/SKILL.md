# コンサル資料スライド作成（16:9画像）

HTML（1280×720）でスライドを組み、`scripts/render.py` で PNG（2560×1440）に書き出す。
見た目の手本は、経済産業省の委託調査報告書（令和3年度、戦略コンサルが作成したもの）のスライド。

## 構成（上から順に）
1. **スライドタイトル**：そのページのテーマを名詞句で書く（例：「TESLAの収益体質」）。38px・極太・黒。1行に収め、下線や帯は付けない。タイトルの上に章ラベルなどは置かない。
2. **キーメッセージ**：そのページの結論を文で書く（例：「〜していることから、〜と考えられる」）。20px・標準の太さ（太字にしない）・黒。1〜2行。囲み枠や背景色は付けない。
3. **コンテンツ**：1カラムか2カラムのパネルで構成する。各パネルには中央揃えの見出し（19px・標準の太さ）を置き、その下に黒の細線を引く。
4. **フッター**：左下に「出所：〇〇より」（12px・グレー）、右下にページ番号（必要ならコピーライトも）。

## デザインルール
- **色**：黒、白、グレー（#7f7f7f / #767676 / #e6e6e6）、紫3段階（#a100ff / #d29bff / #ecd6ff）だけを使う。背景は白。
- **#a100ff を使う場所**：
  - グラフ上に直接書く注釈（例：「BEV市場では圧倒的なNo1」）。太字の紫テキストで書き、枠で囲まない
  - 主役のデータ系列や棒（比較対象の系列は黒、濃いグレー、#d29bff にする）
  - 本文や箇条書きの中の重要な語句（紫の文字色）
  - プロセスやステップを表す矢羽根（`.chevron`）、注目させたい箇所を囲む枠線
- **#ecd6ff を使う場所**：本文中の蛍光ペン風ハイライト（`.hl`）、表のセルの塗り、トレンドを示す半透明の太い矢印。
- **グラフ**：インライン SVG で描く。補助線（グリッド線）は引かない。軸は黒の細線にする。凡例は使わず、系列名を線や棒の横に直接書き、数値ラベルを付ける。単位は左上に「単位：千台」のように書く。トレンド矢印は棒や線より先に描いて背面に置き、数値ラベルに重ねない。
- **表**：見出し行の下に黒の実線、行の区切りは点線。行見出しは濃いグレーの塗りに白抜きの太字。該当セルは #ecd6ff で塗り、特に強調したいセルは #a100ff で塗って白抜きにする。
- **番号**：黒い四角に白抜き数字（`.num-sq`）か、グレーの丸数字（`.num-circle`）。
- **コメント・考察**：薄いグレーのボックス（`.gray-box`）に、太字の見出し1文と箇条書きを入れる。
- **フォント**：ヒラギノ角ゴシック。本文16px前後。グラフの軸ラベルや数値は16〜20pxと大きめにする。注記以外で12px未満は使わない。
- **情報量**：具体的な数値、固有名詞、比較軸を入れて、ページを情報で埋める。中身のない言葉は使わない。

## AI生成っぽさを避けるためのNG
- グラデーション、ドロップシャドウ、光彩、ぼかし、ガラス風の表現
- 角丸カード（角丸は丸数字以外では使わない）、背景の装飾図形
- 絵文字、要素ごとにアイコンを並べること、アイコン付きの3カードを並べるだけの定型レイアウト
- 余白だらけで情報の薄いページ、紫を全体に多用すること

## イラスト（必要な場合のみ）
- 概念の説明、関係者や立場の図示（例：「現）大手自動車OEM」の発言）など、絵があると理解が早くなる場合だけ使う。データ中心のページには入れない。
- 1枚につき1点まで。小さく添える程度にし、主役はテキストと図表にする。
- unDraw から英語キーワードで検索し、#a100ff に色を置き換えて保存する：
  ```bash
  python3 ~/.claude/skills/consulting-slide/scripts/undraw.py search "team"
  python3 ~/.claude/skills/consulting-slide/scripts/undraw.py get <URL> <出力先>/illust.svg
  ```
- HTML では `<img src="illust.svg">` のように相対パスで読み込む。

## 手順
1. ユーザーからスライドの内容（テーマ、伝えたいこと、データ、出所）を受け取る。キーメッセージやデータが足りなければ確認する。
2. コンテンツの型を決める（左右2パネルのグラフ＋考察、比較表、矢羽根のプロセス＋説明ボックス、マトリクス表など）。
3. `templates/base.html` をコピーして、`{{…}}` の部分を埋める。使わない要素（コピーライトなど）は削除する。
4. 書き出す：
   ```bash
   python3 ~/.claude/skills/consulting-slide/scripts/render.py slide.html slide.png
   ```
5. Read ツールで PNG を開いて確認し、問題があれば HTML を直して書き出し直す。確認項目：
   - はみ出し、重なり、不自然な改行がないか
   - キーメッセージとコンテンツの内容が合っているか
   - 紫が強調箇所だけに使われているか、上記のNGに当てはまる表現がないか
   - 数値の単位と出所が書かれているか
6. 出力先は、ユーザーの指定がなければカレントディレクトリ。HTML と PNG を同じ名前で並べて保存する（例：`slide_01.html` と `slide_01.png`）。
